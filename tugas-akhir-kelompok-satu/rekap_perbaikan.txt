--------------------------------------------------------------------------------
a. Pada pengujian awal modul Laporan, terdapat kegagalan interaksi DOM/XPath pada input pencarian dan seleksi kalender.

2. ANALISIS AKAR PENYEBAB (ROOT CAUSE)
--------------------------------------------------------------------------------
- Locator `typeDropdown` sebelumnya menggunakan selector `//div[contains(.,'field')]/..//input` yang menjangkau parent form dan secara tidak sengaja menargetkan input Date urutan pertama.
- Komponen Date Picker pada web React memerlukan pengetikan tanggal terformat dengan jeda interaksi agar state internal form terbarui secara sempurna.
- Halaman Download Absen V2 menggunakan rute khusus `/laporan/new-generate` pada web Hadir Magang.
- Step definition pada `AdminLaporanSteps.java` sempat memiliki data hardcode terpisah yang perlu disinkronkan dengan Page Object.
