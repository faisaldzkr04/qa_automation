REKAPITULASI LENGKAP PERBAIKAN PENGUJIAN OTOMATIS (CUCUMBER BDD & SELENIUM)
Modul: Full Web UI Regression (Termasuk Admin Laporan & Approvals)
================================================================================

1. LATAR BELAKANG MASALAH & PENYEMPURNAAN
--------------------------------------------------------------------------------
a. Pada pengujian awal modul Laporan, terdapat 24 failed tests dari skenario negatif ("Search Laporan with invalid name") akibat kegagalan interaksi DOM/XPath pada input pencarian.
b. Pengujian sebelumnya berjalan sangat cepat dan tidak menampilkan animasi visual (seperti mengetik nama, memilih kalender tanggal, atau membuka dropdown).
c. Eksekusi pengujian per-menu sempat terduplikasi (berjalan 4 kali, bukan 2 kali) akibat adanya runner API yang memindai seluruh folder feature.
d. Komponen pengujian API yang sudah tidak diperlukan perlu dibersihkan agar suite murni menguji fungsionalitas Web UI.

2. ANALISIS AKAR PENYEBAB (ROOT CAUSE)
--------------------------------------------------------------------------------
- Locator `searchNamaInput` dan `searchBtn` sebelumnya terlalu generik dan tidak memicu event `ENTER`/`onChange` di web React.
- Komponen Date Picker menggunakan dialog interaktif yang memerlukan aksi pemilihan visual dan tombol Simpan.
- `ApiTestRunner` dalam `testng.xml` memindai seluruh feature file UI, sehingga saat difilter per-menu, kedua runner mengeksekusi skenario yang sama (2 + 2 = 4 tes).

3. TINDAKAN PERBAIKAN & PENYEMPURNAAN YANG DILAKUKAN (FIXES & ENHANCEMENTS)
--------------------------------------------------------------------------------
a. Perbaikan Interaksi & Animasi Visual Realistis:
   - Menambahkan simulasi pengetikan karakter per karakter (`typeSlowly`) dengan jeda realistis untuk pencarian nama pada skenario Positif ("Admin") dan Negatif ("InvalidUserXYZ999").
   - Menambahkan animasi pemilihan tanggal pada popup Date Picker beserta penekanan tombol Save/Simpan.
   - Menambahkan visual highlight pada tombol Filter Unit Departemen, opsi dropdown, dan tombol Reset.
   - Mengaktifkan pengisian otomatis form pada menu Download Absen (V1), Download Absen v2, dan Sisa Cuti.

b. Penyempurnaan Skenario Positif & Negatif per Menu:
   - Menambahkan langkah pencarian nama pada skenario positif di `09_admin_laporan_approval.feature`, sehingga setiap menu laporan memiliki tepat 1 tes Positif dan 1 tes Negatif (2 tes per menu).

c. Pembersihan Runner API:
   - Menghapus komponen pengujian API (`ApiTestRunner.java`, `ApiAuthSteps.java`, `04_api_auth.feature`, dan suite API pada `testng.xml`).
   - Eksekusi kini terfokus 100% pada Web UI `TestRunner.java` tanpa duplikasi.
